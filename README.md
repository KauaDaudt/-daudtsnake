# 🐍 DaudtSnake

Jogo da cobrinha medieval com ranking global, login com Google e doações via Pix.

## 🎮 Funcionalidades

- Login com Google OAuth2
- Jogo da cobrinha com mapa medieval e 3 skins (Verde, Dragão, Cascavel)
- Ranking global com top 10 jogadores
- Doações via Pix com QR Code dinâmico (Mercado Pago)
- Perfil personalizável com avatar e skin

## 🛠️ Tecnologias

**Frontend:** Angular 19 + TypeScript + SCSS  
**Backend:** ASP.NET Core 8 (C#) + Entity Framework  
**Banco:** PostgreSQL (Supabase)  
**Auth:** Google Identity Services  
**Pagamento:** Mercado Pago API (Pix dinâmico)  
**Deploy:** Railway
